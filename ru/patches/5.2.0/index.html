Патч 5.2.0¶

Что изменилось в игровых данных с 5.1.2 до 5.2.0 — по сравнению двух версий. Зачёркнутое удалено, выделенное добавлено. Сравниваются только данные: изменения в работе кода здесь не видны.

Ключевые слова¶

Изменено (2)¶

Название Изменение
Фантомные удары Попадание атакой оружием ближнего боя может вызвать фантомный → призрачный удар по случайному противнику → врагу поблизости → рядом, в → включая том → исходную числе по исходной цели → цель. Считается только удар самого оружия: снаряды, чары → заклинания и удары по области → площади, такие как молния Смайта → Кары скипетра, - нет. Он наносит 15% → 24% рассчитанного урона исходного удара → попадания до защиты цели. Модификаторы урона повторно не применяются, новый крит и эффекты → он не вызывает эффектов при попадании. Он бросает собственный критический удар с шансом и уроном крита исходного попадания плюс бонусами для призрачных ударов. Он не срабатывают → накапливает недугов и накапливает половину оглушения исходного попадания, увеличенную накоплением оглушения для призрачных ударов. Каждые полные 100% шанса гарантируют один фантомный → призрачный удар, → ; остаток проверяется → даёт шанс ещё на ещё один. Только «Бесконечный призрак» разрешает → позволяет фантомным → призрачным ударам вызывать следующие → новые фантомные → призрачные удары.
Чары Атаки посохов и Смайты скипетров используют бонусы чар вместо бонусов ближнего или дальнего боя; сам взмах скипетра - ближний бой. Применение завершает комбо и не получает бонусов удара с разбега.
