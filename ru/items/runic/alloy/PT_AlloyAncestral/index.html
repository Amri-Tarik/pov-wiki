Родовой сплав¶

В каждой жиле - память тела, дыхания и воли.
Тема Жизнь
Эффект Ковка: свойства темы «жизнь» выпадают намного чаще
Потенциал 0
Азуритовая пыль 5
Выплавляется из Руноносная медная руда

Все сплавы: Сплавы. Насколько вероятнее: как сплавы смещают выпадение.

Свойства, которые он поддерживает (329)¶

Ковка со сплавом «Родовой сплав» делает эти свойства гораздо вероятнее, где бы они ни выпадали; на конкретном предмете в пул ковки попадают только подходящие ему. У свойства, которое выпадает на разные виды предметов, своя строка для каждого.
