# Path of Valheiman DB

Справочник по [Path of Valheiman](https://valheim.hexium.gg/mods/treextr/PathOfValheiman), собранный
из файлов мода. Мод для Valheim, вдохновлённый Path of Exile: дерево навыков, ремёсла и добыча.

Каждая страница здесь создаётся из файлов самого мода. Текст формирует код игры, поэтому он
совпадает с тем, что вы видите в игре, и обновляется с каждым патчем.

!!! tip "Планируете билд?"
    Чтобы спланировать свой билд или посмотреть билды других игроков, заходите на
    [povbuilds.com](https://povbuilds.com) — планировщик билдов для Path of Valheiman.

## Ключевые слова

Подчёркнутые ключевые слова ведут на статьи из внутриигровой вики мода и показывают определение
при наведении. Через поиск можно найти любой узел или ключевое слово.

!!! info "Нереализованное содержимое"
    В файлах игры есть незаконченное содержимое: узлы-заглушки или характеристики без нормального
    текста. Оно тоже приведено здесь, с пометкой **Не реализовано** или **Незаконченный текст**.

!!! note "Перевод"
    Игровой текст взят из русского перевода мода и Valheim. Остальной текст сайта переведён
    отдельно; если заметите ошибку, сообщите о ней на GitHub.
