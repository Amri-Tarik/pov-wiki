Категории свойств¶

У каждого свойства предмета есть тема; его могут поддерживать сплавы Рунической наковальни, оно может входить в семейства и всегда состоит в группе. Категории взяты из собственного каталога свойств мода, и у каждого свойства они указаны на его странице.

Темы¶

Тема свойства говорит, что это за свойство. Зачарования разложены по темам, а сплавы поддерживают свойства своей темы.

Общие группы¶

На предмете может быть только одно свойство из каждой группы. В 378 группах больше одного свойства: общие группы. Каждое остальное свойство — группа само по себе.

Данные из Path of Valheiman 6.0.12, извлечены 2026-11-13.
